واجهات السيرفر المتاحة للألعاب (HOME ANAB)
==========================================
اللعبة تُفتح من التلفاز على نفس عنوان السيرفر، فتستطيع أن تنادي هذه الواجهات بـ fetch مباشرة.
خارج التلفاز (مثلاً عند فتح الملف على كمبيوتر) لا تعمل، فعلى اللعبة أن تتجاهل أي خطأ بهدوء.

1) إضافة نجوم لرصيد الطفل الذي يلعب الآن
   POST /api/tv/stars/earn
   الجسم JSON:  {"amount": 1..10, "game": "اسم اللعبة", "reason": "السبب (اختياري)"}
   الرد 200:    {"ok": true, "added": 4, "balance": 23, "today": 9, "limit": 20, "capped": false}
     - added: ما أُضيف فعلاً. قد يكون أقل من المطلوب أو صفراً إذا بلغ الطفل الحد اليومي،
       فاعرض للطفل عدد added لا العدد المطلوب، ولا تعرض شيئاً إذا كان صفراً.
     - limit: الحد اليومي لكل شخص من كل الألعاب معاً (الافتراضي 20، يغيّره الأب أو الأم
       من «نجوم العائلة» على الهاتف أو الكمبيوتر؛ 0 = الألعاب لا تضيف نجوماً).
   الأخطاء: 400 (عدد غير صالح أو بلا اسم لعبة)، 401 (لا يوجد شخص مسجّل على التلفاز)، 403 (ليس من التلفاز).
   كل إضافة تظهر في سجل النجوم: «🎮 فلان ربح ⭐ 4 — اسم اللعبة: السبب».

   مثال:
     fetch("/api/tv/stars/earn", { method: "POST", credentials: "same-origin",
       headers: { "Content-Type": "application/json" },
       body: JSON.stringify({ amount: 4, game: "سارة والتفكير", reason: "أنهى 20 سؤالاً" }) })
       .then((r) => (r.ok ? r.json() : null)).then((d) => { if (d && d.added) { /* أظهر +d.added ⭐ */ } }).catch(() => {});

   للتجربة: الخادم التجريبي tools/mock.py يحاكي هذه الواجهة (رصيد 10، حد يومي 20).
