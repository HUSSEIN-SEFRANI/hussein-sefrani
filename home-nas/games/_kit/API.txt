واجهات السيرفر المتاحة للألعاب (HOME ANAB)
==========================================
اللعبة تُفتح من التلفاز على نفس عنوان السيرفر، فتستطيع أن تنادي هذه الواجهات بـ fetch مباشرة.
خارج التلفاز (مثلاً عند فتح الملف على كمبيوتر) لا تعمل، فعلى اللعبة أن تتجاهل أي خطأ بهدوء.

1) إضافة نجوم لرصيد الطفل الذي يلعب الآن
   POST /api/tv/stars/earn
   الجسم JSON:  {"amount": 1..10, "game": "اسم اللعبة", "reason": "السبب (اختياري)"}
   الرد 200:    {"ok": true, "added": 4, "balance": 23, "today": 9, "limit": 20, "capped": false}
     - added: ما أُضيف فعلاً. قد يكون أقل من المطلوب أو صفراً إذا بلغ الطفل الحد اليومي،
       فاعرض للطفل عدد added لا العدد المطلوب، ولا تعرض شيئاً إذا كان صفراً.
     - limit: الحد اليومي لكل شخص من كل الألعاب معاً (الافتراضي 20، يغيّره الأب أو الأم
       من «نجوم العائلة» على الهاتف أو الكمبيوتر؛ 0 = الألعاب لا تضيف نجوماً).
   الأخطاء: 400 (عدد غير صالح أو بلا اسم لعبة)، 401 (لا يوجد شخص مسجّل على التلفاز)، 403 (ليس من التلفاز).
   كل إضافة تظهر في سجل النجوم: «🎮 فلان ربح ⭐ 4 — اسم اللعبة: السبب».

   مثال:
     fetch("/api/tv/stars/earn", { method: "POST", credentials: "same-origin",
       headers: { "Content-Type": "application/json" },
       body: JSON.stringify({ amount: 4, game: "سارة والتفكير", reason: "أنهى 20 سؤالاً" }) })
       .then((r) => (r.ok ? r.json() : null)).then((d) => { if (d && d.added) { /* أظهر +d.added ⭐ */ } }).catch(() => {});

   للتجربة: الخادم التجريبي tools/mock.py يحاكي هذه الواجهة (رصيد 10، حد يومي 20).


2) صور العائلة (من «الأشخاص» في تطبيق الصور: الأشخاص الذين سمّاهم الأهل فقط)
   GET /api/tv/family/people?limit=40&faces=6
   الرد 200:  {"people": [{"id": 12, "name": "جدّو", "faces": [881, 902, 915], "count": 37}, ...]}
     - faces: أرقام وجوه هذا الشخص (الأوضح أولاً). الصور:
         /api/tv/face/<رقم الوجه>          صورة الوجه مربعة (JPEG)، مناسبة لبطاقة «من هذا؟» أو الذاكرة
         /api/tv/face/<رقم الوجه>/photo    الصورة الكاملة التي فيها الوجه، مناسبة للبازل
     - تأتي من صور الطفل نفسه، والمساحة العائلية المشتركة، وصور من اختار «صوري على التلفاز».
     - قد تكون القائمة فارغة (لم يُفعَّل تمييز الوجوه أو لم تُسمَّ الوجوه بعد): اعرض للطفل رسالة لطيفة
       واطلب من الأهل تسمية الأشخاص في تطبيق «الصور» ← «الأشخاص»، أو استعمل بديل اللعبة (مثل مجلد family).
   الأخطاء: 401 (لا يوجد شخص مسجّل على التلفاز)، 403 (ليس من التلفاز)، 404 (وجه غير مسموح).

   مثال:
     const r = await fetch("/api/tv/family/people", { credentials: "same-origin" }).catch(() => null);
     const people = r && r.ok ? (await r.json()).people : [];
     // صورة: `/api/tv/face/${people[0].faces[0]}`

3) نتيجة سؤال تعليمي (لتقرير الأهل الأسبوعي: أين يخطئ الطفل أكثر)
   POST /api/tv/learn/result
   الجسم JSON:  {"game": "جدول الضرب", "topic": "7×8", "ok": false}
     - game: اسم اللعبة. topic: ما سُئل عنه باختصار (الحرف، الكلمة، العملية…)، حتى 80 حرفاً.
     - أرسل واحدة لكل إجابة في الألعاب التعليمية فقط، ولا تنتظر الرد، وتجاهل الأخطاء.
   الرد 200:  {"ok": true}

   للتجربة: tools/mock.py يحاكي 2) بوجوه مرسومة (أو صور في tools/faces/<الاسم>/)، ويطبع 3).
