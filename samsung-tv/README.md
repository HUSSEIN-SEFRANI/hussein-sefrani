# مدير تلفاز سامسونغ (Samsung TV Manager)

أداة تعمل على حاسوبك **المتصل بنفس شبكة التلفاز**، وتقدّم واجهة ويب عربية لـ:

| الصفحة | ماذا تفعل |
|---|---|
| **البحث عن الأجهزة** | تبحث عن أجهزة سامسونغ (Tizen 2016+) في الشبكة تلقائياً (SSDP + فحص الشبكة) أو بإدخال عنوان IP يدوياً |
| **واجهتي** | واجهة نظيفة بها تطبيقاتك المفضّلة فقط + ريموت كامل على الشاشة |
| **التطبيقات والتنظيف** | تعرض كل التطبيقات المثبّتة، وتعلّم غير الضروري منها (TV Plus، Gaming Hub، Samsung Health…)، وتتيح الإخفاء/المفضلة/التشغيل/الحذف |
| **حظر الإعلانات** | تُنشئ قائمة حظر لنطاقات إعلانات وتتبّع سامسونغ (للراوتر، Pi-hole، AdGuard) + قائمة بإعدادات الخصوصية داخل التلفاز |
| **وضع المطوّر / الخبير** | يعرض هل وضع المطوّر مفعّل، وشرح تفعيله خطوة بخطوة |

## التشغيل

يحتاج فقط **Python 3.8+** (بدون أي مكتبات إضافية):

```bash
cd samsung-tv
python3 tv_manager.py          # يفتح المتصفح على http://localhost:8765
python3 tv_manager.py --scan   # بحث سريع في الطرفية فقط
```

على ويندوز: `py tv_manager.py`

## أول استخدام

1. شغّل التلفاز واضغط **«ابحث في الشبكة»**.
2. اختر التلفاز ← سيظهر على شاشة التلفاز طلب اتصال: اضغط **«سماح / Allow»** (مرة واحدة فقط).
3. من **«التطبيقات والتنظيف»**: اضغط «تحميل التطبيقات»، ثم «إخفاء كل غير الضروري»، وضع ⭐ على ما تريده.
4. افتح **«واجهتي»** واستمتع.

## تفعيل وضع المطوّر (الخبير)

لا تسمح سامسونغ بتفعيله عن بُعد، يجب فعله بالريموت مرة واحدة:

1. افتح **Apps / التطبيقات** على التلفاز.
2. اكتب `12345` بالريموت.
3. فعّل **Developer mode** وأدخل عنوان IP لحاسوبك (يظهر في صفحة «وضع المطوّر»).
4. أعد تشغيل التلفاز.

## حذف التطبيقات فعلياً

* ثبّت [Tizen Studio](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/installing-tv-sdk.html) (يحتوي أداة `sdb`).
* مع تفعيل وضع المطوّر، سيظهر زر **«حذف»** بجانب كل تطبيق.
* **تنبيه صريح:** تطبيقات المصنع المثبّتة مسبقاً محمية في أغلب الموديلات ولا تُحذف حتى في وضع المطوّر؛ الحل العملي هو إخفاؤها من واجهتك وحظر إعلاناتها عبر DNS.

## حظر الإعلانات

الإعلانات تأتي من خوادم سامسونغ، فأفضل حظر يكون على مستوى الشبكة:

* **Pi-hole / AdGuard Home / الراوتر:** نزّل القائمة من صفحة «حظر الإعلانات» بالصيغة المناسبة.
* **بدون أجهزة إضافية:** في التلفاز ← الإعدادات ← عام ← الشبكة ← إعدادات IP ← DNS يدوي ← `94.140.14.14` (AdGuard DNS).
* المستوى «القوي» قد يعطّل بعض بلاطات Smart Hub — جرّب «الآمن» أولاً.

## الخصوصية والأمان

* الخادم يستمع على `127.0.0.1` فقط، ولا يقبل إلا عناوين الشبكة المحلية، ويرفض الطلبات من مواقع أخرى.
* رمز الاقتران والمفضلة تُحفظ محلياً في `tv_data.json` (مستثنى من git).
* الأداة **لا تلمس قائمة الخدمة المخفية (Service Menu)** لأن تغييرها قد يعطّل التلفاز.
