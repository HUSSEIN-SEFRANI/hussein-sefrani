=============================================
  تثبيت تطبيق «مواقيت البيت» على تلفاز سامسونغ
=============================================

الملف: dist\MawaqitBayt.wgt  (غير موقّع — سامسونغ تطلب التوقيع)

شرط لا مفرّ منه: وضع المطوّر يجب أن يكون مفعّلاً على التلفاز
(Apps ← 12345 ← Developer mode = On ← عنوان الكمبيوتر ← إعادة تشغيل التلفاز).
بدونه لا يقبل التلفاز أي تطبيق من خارج متجر سامسونغ.

الخطوات في Tizen Studio:
 1) Tools ← Package Manager ← Extension SDK: ثبّت «TV Extensions» و «Samsung Certificate Extension».
 2) Tools ← Device Manager ← Remote Device Manager ← «+» ← اكتب عنوان التلفاز 192.168.0.8 والمنفذ 26101
    ← شغّل المفتاح Connection.
 3) Tools ← Certificate Manager ← «+» ← Samsung ← TV ← أنشئ شهادة (يحتاج حساب سامسونغ)،
    ويضيف رقم DUID للتلفاز المتصل تلقائياً.
 4) File ← Import ← Tizen ← Tizen Project ← اختر مجلد tizen-app
    ← زر يمين على المشروع ← Build Signed Package
    ← زر يمين ← Run As ← Tizen Web Application   (يثبّته على التلفاز).

بعد التثبيت: تجد «مواقيت البيت» في قائمة تطبيقات التلفاز.
 - زر الرجوع في الريموت يغلق التطبيق.
 - الأذان يعمل ما دام التطبيق مفتوحاً (سامسونغ لا تسمح للتطبيقات بالعمل في الخلفية).
 - لإضافة صوت أذان حقيقي: ضع adhan.mp3 في مجلد tizen-app ثم شغّل:  py make_tizen.py  ثم أعد الخطوة 4.
