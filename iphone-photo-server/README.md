# 📷 سيرفر صور الآيفون (iPhone Photo Server)

سيرفر محلي يعمل على جهاز الكمبيوتر (Windows / macOS / Linux) لحفظ صور وفيديوهات الآيفون
عبر شبكة الـ Wi-Fi المنزلية. **مستقل بالكامل**: لا يحتاج إنترنت، ولا حساب سحابي، ولا تطبيق على الهاتف —
فقط متصفح Safari.

## المميزات

- رفع مئات الصور والفيديوهات دفعة واحدة من Safari مع شريط تقدم لكل ملف، وإعادة محاولة تلقائية عند انقطاع الاتصال.
- **منع التكرار**: كل ملف له بصمة SHA-256، فلا تُحفظ الصورة نفسها مرتين حتى لو رفعتها أكثر من مرة.
- **ترتيب تلقائي** في مجلدات حسب تاريخ الالتقاط (من بيانات EXIF): `storage/photos/2024/07/IMG_1234.HEIC`.
- يحفظ الملف **الأصلي كما هو** (HEIC، JPG، PNG، MOV، MP4 …) بدون ضغط.
- معرض صور مرتب حسب الشهر، مع عارض بملء الشاشة، سحب للتنقل، تشغيل الفيديو، تنزيل وحذف.
- معاينة صور HEIC حتى على متصفحات الكمبيوتر التي لا تدعمها (تحويل تلقائي إلى JPEG للعرض فقط).
- حماية بكلمة مرور + حماية من تخمين كلمة المرور.
- الحذف ينقل الملف إلى مجلد `storage/trash` ولا يمسحه نهائياً.
- دعم **الرفع التلقائي** عبر تطبيق «الاختصارات» (Shortcuts) في iOS باستخدام رمز API.
- واجهة عربية، تدعم الوضع الليلي، ويمكن إضافتها للشاشة الرئيسية كتطبيق.

## التشغيل

### المتطلبات
- [Python 3.9 أو أحدث](https://www.python.org/downloads/) — على ويندوز فعّل خيار **Add Python to PATH** أثناء التثبيت.

### ويندوز
انقر نقراً مزدوجاً على `start-windows.bat`.
في المرة الأولى سيتم تثبيت المكتبات تلقائياً ثم يطلب منك اختيار كلمة مرور.

### macOS / Linux
```bash
./start.sh
```

بعد التشغيل ستظهر رسالة فيها الرابط، مثلاً:
```
     ->  http://192.168.1.20:8080
```

### من الآيفون
1. تأكد أن الآيفون والكمبيوتر متصلان **بنفس شبكة Wi-Fi**.
2. افتح الرابط في Safari وأدخل كلمة المرور.
3. اضغط «اختيار الصور» → حدد الصور → «إضافة».
4. اترك الصفحة مفتوحة حتى يظهر «✅ اكتمل الرفع».

> 💡 لجعلها كتطبيق: زر المشاركة في Safari ← **إضافة إلى الشاشة الرئيسية**.

> 💡 للحفاظ على الصيغة الأصلية (HEIC) والجودة الكاملة: في نافذة اختيار الصور على iOS
> اضغط **«الخيارات»** واختر **«الحالي» / Current** بدلاً من «الأكثر توافقاً»، إن كان الخيار متاحاً في إصدار iOS لديك.

## جدار الحماية (ويندوز)
عند التشغيل الأول قد يظهر تنبيه من Windows Defender Firewall — اختر **السماح على الشبكات الخاصة (Private)**.
إن لم يفتح الرابط من الهاتف، تأكد أن الشبكة مُعرّفة كـ «خاصة» في إعدادات ويندوز.

## الأوامر والخيارات

| الأمر | الوظيفة |
|---|---|
| `python server.py` | تشغيل السيرفر |
| `python server.py --port 9000` | تغيير المنفذ (يُحفظ في الإعدادات) |
| `python server.py --storage "D:\Photos"` | تغيير مجلد الحفظ (يُحفظ في الإعدادات) |
| `python server.py --set-password` | تعيين كلمة مرور جديدة |
| `python server.py --rescan` | فهرسة صور نسختها يدوياً إلى مجلد `photos`، وحذف سجلات الملفات المحذوفة |

على ويندوز يمكن تمرير نفس الخيارات للملف: `start-windows.bat --port 9000`.

كل الإعدادات محفوظة في `config.json` (يُنشأ تلقائياً — لا تشاركه مع أحد لأنه يحتوي على رمز API).

## هيكل التخزين

```
storage/
├── photos/          ← صورك الأصلية مرتبة سنة/شهر (هذا المجلد هو المهم للنسخ الاحتياطي)
│   └── 2024/07/IMG_1234.HEIC
├── trash/           ← الملفات المحذوفة من المعرض
├── library.db       ← فهرس الصور (SQLite)
└── .cache/          ← مصغرات ومعاينات (يمكن حذفه بأمان، يُعاد إنشاؤه)
```

## الرفع التلقائي عبر «الاختصارات» (اختياري)

1. من صفحة **الإعدادات** في السيرفر انسخ **رابط الرفع** و**الرمز (Token)**.
2. في تطبيق «الاختصارات» أنشئ اختصاراً جديداً:
   - **البحث عن صور** (Find Photos): مثلاً «تاريخ الإنشاء — اليوم».
   - **تكرار مع كل عنصر** (Repeat with Each)، وداخله:
     - **الحصول على محتويات URL** (Get Contents of URL):
       - الرابط: `http://IP:8080/api/upload`
       - الطريقة: `POST`
       - الترويسات (Headers): `Authorization` = `Bearer الرمز`
       - نص الطلب: **Form** ← حقل نوعه **ملف** باسم `file` وقيمته «عنصر التكرار».
3. من تبويب «الأتمتة» يمكن تشغيله تلقائياً، مثلاً عند الاتصال بشبكة Wi-Fi المنزل.

الصور المرفوعة مسبقاً يتم تجاهلها تلقائياً، لذا لا مشكلة في إعادة رفع نفس الصور.

### واجهة API

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/api/upload` | حقل `file` (ملف أو أكثر)، و`last_modified` اختياري (ميلي ثانية) |
| GET | `/api/media?offset=0&limit=120&kind=all\|photos\|videos` | قائمة الملفات |
| GET | `/api/stats` | الإحصائيات |
| DELETE | `/api/media/<id>` | نقل ملف إلى سلة المحذوفات |
| GET | `/thumb/<id>` · `/view/<id>` · `/download/<id>` | مصغرة · معاينة · الملف الأصلي |

المصادقة: جلسة تسجيل دخول، أو الترويسة `Authorization: Bearer <token>`.

## ملاحظات أمان
- السيرفر مصمم للشبكة المنزلية فقط. **لا تفتح المنفذ على الراوتر للإنترنت** (الاتصال HTTP غير مشفر).
- غيّر الرمز من صفحة الإعدادات إذا شككت أن أحداً اطلع عليه.
